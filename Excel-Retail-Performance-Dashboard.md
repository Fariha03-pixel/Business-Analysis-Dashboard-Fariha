# Excel Retail Performance Dashboard

### 📊 Project Overview
This Excel project analyses the sales performance of a retail company across multiple regions, products, and time periods. It uses pivot tables, charts, and formulas to provide insights into sales trends, profit margins, and top-performing products.

### 🎯 Objectives
- Analyse total sales and profit by region and category  
- Identify top-performing and underperforming products  
- Track month-by-month revenue trends  
- Create an interactive dashboard for management reporting  

### 🧠 Key Excel Skills Used
- Pivot Tables and Pivot Charts  
- Data Cleaning using Remove Duplicates and Filters  
- Advanced Formulas: VLOOKUP, IF, SUMIFS, and AVERAGEIFS  
- Conditional Formatting  
- Dashboard Design using Charts and Slicers  

### 📈 Insights Discovered
1. The South Region generated the highest total revenue (42% of total sales).  
2. Electronics and Furniture categories had the largest profit margins.  
3. Q3 sales showed a 25% increase compared to Q2 due to promotional campaigns.  
4. Products with discounts above 15% led to lower profits despite higher sales volume.  

### 🧩 Tools Used
- Microsoft Excel  
- Sample dataset (Retail Sales Dataset from Kaggle)  

### 📁 Dataset
You can download a free retail dataset from [Kaggle’s Superstore Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final).
